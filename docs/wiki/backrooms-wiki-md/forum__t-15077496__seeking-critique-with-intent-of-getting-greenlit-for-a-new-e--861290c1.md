> {Dr. Greg} "Hello Mr. Fernand…

1. There should be a space between 'Dr.' and 'Greg'.  
2. There is no need to put quotation marks around the sentences. I would rewrite this as:

> **Dr. Greg**: Hello Mr. Fernand…

> …Dr. Greg Smith…  
> {Dr.Greg}…

If one's name is Greg Smith, you should say their last name and not their first name.

E.G.:

> Dr. Greg Smith should be called 'Dr. Smith', not 'Dr. Greg'

> …emotions right now

Add a period at the end of the sentence.

> …\*Toni Sighs\*…

Remove 'Toni' and the capitalization on 'Sighs'

> Y.yeah…

Replace the period with a hyphen (-)

> You understand this right?

Add a comma after 'this'.

> Mr. Fernand… Why don't

Remove capitalization on 'Why'.

> Sure…So me…

Do not capitalize 'so' here.

> …same page so, it…

Put the comma before 'so', not after it.

> ..was going on, It was…

Remove capitalization on 'It'.

> …hole was gone, Howard was…

Put an 'and' before Howard's name.

> {Dr.Greg} "Yes Mr.Ferand…

You spelt 'Fernand' wrong.

I found some code for audio that may work, but I'm not sure:

[[include :snippets:html5player  
|type=audio  
|url=audio file url  
]]

If you want it to autoplay:

[[include :snippets:html5player  
|type=audio  
|url=audio file url  
|autoplay=true  
]]

You also need to upload files (such as images, audio, etc.) to your page so you can use them. First, scroll to the bottom of your page and click the 'Files' option. Then, upload the file you want. After that, you can click on the file and a link that contains the file will open. Copy + paste that link.

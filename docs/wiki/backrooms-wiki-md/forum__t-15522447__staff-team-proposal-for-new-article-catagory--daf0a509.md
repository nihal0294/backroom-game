I present to you:

# Enigmatic Objects

I imagined that an Enigmatic Object would be an object that there is only 1 of in the entirety of the Backrooms (Or at the very least, only 1 that is known about) since pretty much all Objects I've seen can be found in great numbers, often across multiple levels. I also imagine that an Enigmatic Object would be very important and/or powerful, for hopefully obvious reasons.

So yeah if this is already a thing with some objects then just ignore this post lol

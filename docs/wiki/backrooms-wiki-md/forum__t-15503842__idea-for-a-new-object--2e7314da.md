There isn’t really much substance to the object. It’s broken and sends stuff to random locations. This reads more like an entry on the Anomalous Objects list on the SCP wiki than an object page about a Backrooms object. What’s going on with the cabinet? Do these cabinets show up in specific places within the Backrooms? Do people attempt to use them? Could they be used in some way (the “hole in the back only visible from inside” bit feels like a useful way to spy on people or entities)? Why ten meters? Why do places need to be unobserved for teleportation to happen?

There’s not enough here to work with for a full object article.

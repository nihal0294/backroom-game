Multiple Questions

11 Mar 2022 02:40

Hey! Sorry for the numerous questions, but I figured I'd post them all at once:

1. Is it alright if a level is an entity itself? I want to make a level where it's just the maw of an inconceivably large, long-muzzled creature. The entry door opens into the back of the mouth and the exit is by the front teeth. But obviously the mouth would attach to something, which loops back to my question.

2. Is there a level like this already? I did a quick search but couldn't find one. Then again, it wasn't too thorough so I might have missed it.

3. Would "inside of a creature's mouth" count as "gore" on this site? Rules say not to post gore and I want to make sure I'm not stepping out of line with this.

4. Is it okay to use entities already confirmed/made by other members? Do I have to get the entity author's permission to reference them?

5. I want to make a new entity that makes their home, and is only found, in this mouth level; should I make that entry first? I ask because I don't know if the level itself will get approved so making an entity for it first seems backwards.

6. The entity I want to make is called the Tooth Fairy (which you can probably already guess what it does), but there's another entity here called the Dentist which also steals teeth. However, that's where the similarities end; do you think it's fine to make this entity even if they both have a habit of stealing teeth?

7. Are level/entity/etc. numbers assigned to a page once it's greenlit, or is it just "grab a number that's open and go"?

Again, apologies for the multiple questions, but I've been brainstorming this level for a couple days and wanted to get all the questions out at once so I'm not spamming the forum or someone's PMs. Thank you.

Re: Multiple Questions

11 Mar 2022 05:10

1. I think it's been done before, but it has to be done well.

2. As stated before I think there is, but with… recent events I can't remember the number exactly.

3. Not particularly. Gore is also allowed on the site (take [Let's Count Together](https://backrooms-wiki.wikidot.com/lets-count-together) for example), but it must be accompanied by a content warning.

4. To reference them you don't have to get permission, but if there are actions or dialogue an entity would make that you're not sure about then contact the author.

5. No. Make the level first and then the entity, but **upload them both at the same time.** I know from experience that cross-linking to non-existent pages isn't the best first look.

6. If they have a different modus operandi and you can make them completely separate from one another, then sure. Try to pull it off.

7. For numbers it's first come, first serve.

Hope this answers everything.

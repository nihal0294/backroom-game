The Entity Epidemic Canon

16 Jul 2025 08:35

A silly little idea of mine for a backrooms canon that, surprisingly enough, isn't set in the Backrooms itself. This is set in the Frontrooms where due to an unknown phenomenon that caused entities and humans to appear in the Frontrooms. It's meant to be set in a post apocalyptic environment, where humans our down to the mere millions in their numbers. Fortunately, a group of survivors called the L.C.S or Little Stone Camp, are dedicated to fighting back against these creatures and repopulating earth, founded by Cooper Morris and Mike Smith, although Cooper went missing. I already have one user helping me on this ( ) but this could be infinitely times better if I had more than that.

If you do want to help, there are things that need to be done before this can become an actual canon:

- 5 pages set in this Canon.
- A logo for both the canon page and canon theme.
- A logo for the L.S.C

If you want to contribute, just leave a link to either the page, or either upload the image here or leave a link to it.

SEEKING GREENLIGHT an entity for the joke level Holy F\*ck Alagie

28 Mar 2022 14:36

### Entity Number: Ψ

### Habitat: Roams freely around [Level Holy F\*ck Alagie](http://backrooms-wiki.wikidot.com/joke-level-holy-fuck-alagie)

# **Description:**

**The Ghost Of Alagie** also known as "**Long Leg**" is a powerful entity that can control pressure and send it out using waves, almost like wave manipulation, this entity creeps around the corners in the level **Holy F\*ck Alagie** at phase one but acts passive towards the wanderer, although if approached the entity will disappear. As in phase 2, the entity changes and becomes super hostile making it hell for the wanderer, in this phase it's better to run away from the creature rather than approaching it. As it will try to crush you with it's high pressure waves that it can project.

# **Characteristics:**

The entity does not have a actual form, the only thing making it slightly visible is the thin outline than resembles a humanoid form, although it's form looks pretty human, it has some differences, it has very long legs which affects the entities height making it seem super tall. Exact height has not be documented yet but we in fact know for sure that it has longer legs than an average human being. The entity also does not have facial or any type of features.

# **Behaviors:**

As we mentioned earlier the entity acts passive in phase one of the level **Holy F\*ck Alagie** but changes its behavior once the wanderer proceeds to phase two due to unknown reasons and strange nature of the entity **Ghost Of Alagie** or in other words **Long Leg**.

# **Abilities:**

This entity has multiple unique abilities, one of the basics being "High Pressure Wave Manipulation" which can crush your bones, other abilities such as being almost invisible and object possession, it has the ability to possess any object withn it's level, usually the **Long Leg** possessed objects will have a outline around them, the outline can either be white or partly transparent but still visible. Some of the less known abilities are that it can project feelings, the feelings of fear and anxiety to be specific.

# **Do's and Dont's:**

**Do:**

- Avoid the entity in phase 2.
- Ignore it's effect's at all cost's.
- Run the opposite direction of the entity in phase 2.

**Don't:**

- Chase it.
- Run towards the entity in phase 2
- Touch entity possessed object's.

I see a couple of formatting errors:

---

![unknown.png](https://media.discordapp.net/attachments/595268235482628097/903239894179127296/unknown.png)

---

See, instead of

```
**DESCRIPTION**

**BEHAVIOURS**

**BIOLOGY**

**Discovery**
```

  
, you should format it like that:

```
+ Description

+ Behaviours

+ Biology

+ Discovery
```

  
That's how you make headings! To make the heading smaller (turn it into a sub-heading), change the + to ++, +++, ++++, +++++, or ++++++ (the more pluses, the smaller the heading is).

Instead of

```
**Entity number**21

**Habitat**Level 38(newly sighted in level 39)
```

  
, it would be best if you changed it to

```
**Entity Number:** 21

**Habitat:** Level 38 (newly sighted in Level 39)
```

  
You forgot the colons and spaces. Levels are commonly written with a capital L. You should include a space before the "(".

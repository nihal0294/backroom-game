This component does not take mobile adaptation into account, causing it to fail to run on mobile devices.

The code contains two instances of .img-box.box-right but no .img-box.box-left; the code for centering center is written as:

```
display: flex;
flex-direction: column;
margin-left: 34%;
```

  
This method of centering is really poor.

There is also some code with unclear meaning, such as:

```
.description-box:nth-child(n) {
z-index: 5;
}
```

I rewrote this component on Backrooms CN; see the details here:

[https://backrooms-wiki-cn.wikidot.com/component:imgb](component__imgb--2814142c.md)

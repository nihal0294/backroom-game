05 Aug 2022 16:58

1. What if I want to rewrite or significantly edit an existing Object page of mine? Would that count as an Entry?

2. What if I want to write a page *about* an object that is already in existence? i.e. the focus of the contest entry is the object, but a page already exists for said object, and there is no intent for it to be rewritten. The entry would be meant to add context and lore to the existing Object page, and would not replace the Object page, but co-exist on the wiki as a separate page. Would this be counted as a valid contest entry?

E.g.:  
Object X — original page  
Object X: Investigative Report — a separate and distinct page that is submitted as a contest entry

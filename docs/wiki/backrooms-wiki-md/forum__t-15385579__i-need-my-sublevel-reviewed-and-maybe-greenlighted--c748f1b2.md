I do not believe this is ready for greenlight. I've decided I won't crit this, but one thing you need to know before continuing seeking crit is to learn the basic wikidot syntax. I found the page very hard and bland to read because you didn't use much of the syntax.

There are two syntaxes that I think you should know right now. The first are bolds and italics. These centralize and emphasize different parts of text. They are usually used for the Level itself when it is mentioned, as well as any entities that don't have an entity page. To use these, type in quadruple asterisks around the text you want to bold, and double slashes (//) to italicize. It should look like this:

**Bold Text**  
*Italic Text*

The other one is lists. They categorize information into easy to read spots. They should be used for the entrances and exits and for other information that requires a list. To make a list, put in an asterisk, then a space, then whatever text you want. Repeat for everything you want to list. It should look:

- Like
- This
- Right
- Here

I suggest to go [here](wikidot-syntax.md) for more information about the syntax and how it can improve your page.

For right now though, I would suggest going to the Discord server for further help.

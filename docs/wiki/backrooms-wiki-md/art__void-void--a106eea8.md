# Void Void

Sorry guys, but I had to get out as fast as possible. I don't know if there are any other emergency pods left, but I hope so.

Ever since the spaceship started malfunctioning, I believed this moment would come. I know, guys, I'm a shameless traitor, I don't deserve this.

But hey, don't be discouraged, maybe we can meet again if I manage to survive. Besides, from the ship's windows I could see some kind of floating [island on the void](level-999.md).

I send you a big hug from the travel and I hope you can live with me, I miss you. Goodbye.

~ Edwin Gabell

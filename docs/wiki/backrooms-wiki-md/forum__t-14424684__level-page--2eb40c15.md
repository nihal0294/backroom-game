As for "securing a page", I'm not sure this is the best way, but I'd say to go up top to the URL, keep it as is, but add a / and the name of the level (ie. <http://backrooms-wiki.wikidot.com/forum/t-14424684/level-123>). It'll hopefully say that no one has created the page and that you have the option to edit it. From there, you can edit it as much as you like.

As for the custom level tiles, I recommend referring to the Syntax Guide found on the Guide Hub, which is found by hovering over the "Info Pages" tab on top. Hope this helps!

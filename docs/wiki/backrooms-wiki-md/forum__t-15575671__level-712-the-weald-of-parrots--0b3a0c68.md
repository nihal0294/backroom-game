This is my first level ever as a backrooms writer, so it probably looks a little rough and non-creative. Like the exit to a random outdoor level, it's not a good idea to do so seeing it from hindsight because random means unpredictable danger. Thank you all for loving it anyway.

I remember that, when I wrote this level back in october 2022, I don't know much about backrooms but I really want to be a part to it. So I picked my favorite entity at that time, which is jerry, and wrote a level based on it. And for now, you might have already seen another one of my work, [Level 610](level-610.md) (originally Level C-712).

And fun fact: I really like to hide some interesting details in my work. For example, "Tommy" is actually "Tom" in the original text (I guess iccaarus must have changed it to make it sound cuter). So… Tom and Jerry, get it?

[[iftags +component]]

> This is a component which lets you link to translations of your page on international language wikis!  
> It has three parameters you can set:  
> **|lang=** This should be set to the languages you want links displayed to, seperated by spaces.  
> To show all of them, you would set **|lang= ar cn de en es fr id it ko pl ptbr ru th tok vn** (those are all the valid language codes, set as many as you want)  
> **|style=** which adds CSS to it. A good use of this is to give it **|style=float:left;** and then after that put the rating module to the right to display them next to each other on the top of the page!  
> **|title=** which changes the default "Languages:" title. A good use of this is in other branches where they can make their local component link to this directly after changing the title! This will default to “Languages:” if not specified.  
> The flags are taken from [Iconfinder](https://www.iconfinder.com/iconsets/142-mini-country-flags-16x16px).
>
> > **NOTE TO STAFF —** The flags are sorted by alphabetical order. Please keep it this way when adding new ones.

> # PROJECT PROGRESS
>
> ### PROJECT NAME: TEM-1
>
> ### PROJECT ITEM: THE EVERYTHING MACHINE
>
> ##### 9/17/2015
>
> ---
>
> [![everything-machine.exe](https://backrooms-wiki.wdfiles.com/local--resized-images/development-of-the-everything-machine/everything-machine.exe/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/development-of-the-everything-machine/everything-machine.exe)
>
> **Origin:** Room 147-C1, next to the power cores.
>
> **Updates:** Currently residing within storage container high priority A-C. Project TEM-1 is undergoing as expected, and is running smoothly. Testing period will begin shortly. As of now, TEM-1 is incredibly fragile, and should be treated as such. Currently in need of Firesalt, Mana, and The Oracle. May need to get some Ant Canners. Currently missing one Hexcube. Will have to make one manually. Current needed materials need for Hexcube; Spire Steel, Molten Iron, basic steel. Expect inspection period to be on 1/20/2016.
>
> **Discovery:** Found in a very hidden sector of alpha section B. Originally thought to have been cleared out, now being searched for more instances of machinery of this Level. Filled largely with many unidentified materials, needing very little work done to be fully assembled.
>
> **Expected Results:** TEM-1 is expected to be capable of fundamentally anything, including a potential escape to The Backrooms themself. TEM-1 has many different sections, however, most of the project is complete. Requesting materials to develop prototype TEM-1.

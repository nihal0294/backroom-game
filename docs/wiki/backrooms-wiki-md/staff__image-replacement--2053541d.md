## See the [Image Replacement Hub](staff__image-replacements--81b9df8a.md) for more information

Here are examples of sites you can use to get creative commons image replacements:

- [Wikimedia Commons](https://commons.wikimedia.org/wiki/Main_Page)
- [Flickr](index.md) (remember to filter "commercial use")
- [Openverse](index.md) (remember to filter only licenses allowing commercial use)
- [Unsplash](index.md), [Pexels](index.md) or [Pixabay](index.md) (only images posted before a certain date! check below for more info)
- [#cc-media-sharing](https://discord.com/channels/695664941247627274/714030848525205555) on the discord

If you cannot find anything, you can ask others for help through [#replacing-non-cc-images](https://discord.com/channels/695664941247627274/1238658752874414081) on the discord.

> If possible, try checking with the author to see if the image you found suits the page, or if they have other images that can be used instead.

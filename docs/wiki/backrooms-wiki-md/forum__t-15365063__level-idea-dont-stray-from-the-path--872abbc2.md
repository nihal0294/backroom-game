Level Idea - Dont stray from the path

05 Nov 2022 11:02

The core idea of this level is that there is a single straight, dirt path that it about 2 to 3 miles long. There is only one entity but this entity will attempt to use illusions, voices and trickey in an attempt to make you leave the path. The entity is the level itself and will reconstruct the surroundings of the path in order to make you step off. The illusions will ramp up as you get along the path and the experience can be mentally scarring for the wanderers that survive.

Entities that attempt to enter will be quickly swallowed by the path. Almond water seems to have a powerful effect on the illusions and when poured on the grass next to the path it will die and become walkable on for a brief period

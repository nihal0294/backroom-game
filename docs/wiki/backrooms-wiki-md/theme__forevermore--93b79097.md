# Forevermore

rating: +19[+](javascript:; "I like it")[–](javascript:; "I don't like it")[x](javascript:; "Cancel my vote")

This theme was created by yours truly, !

This theme was initially for a Valentine's Day kind of entry, but I realized that it pretty much works with any kind of romance-themed articles/tales! In love is La Vie En Rose, right? What better way to show love through the lovey-dovey shades of red and pink!

To use it, put the following code on your page:

[[include :backrooms-wiki:theme:Forevermore]]

blep.

Creating cool lil horizontal rules is possible by typing 5 hyphens "-----". These lines extend across the whole page if it's not placed inside anything, like a blockquote!.

---

If you'd like sections to be categorized more specifically, use titles! These can be created by putting between one-six plus signs "+" at the start of the line.

> ## Gradient Image Block
>
> ---
>
> **This is an alternative to the image block component with a sleeker look.**  
> You can include it with:
>
> > [[include :backrooms-wiki:component:gradient-image-block -=-  
> > |name=image.png  
> > |caption=Image caption to go over the image.  
> > |align=left/right/center  
> > |alt=Alt text description for the image  
> > |caption-align=left/right/center/justify  
> > |caption-size=80%  
> > |width=300px  
> > ]]
>
> It's quite simple, it's mostly the same as using the regular [image block](component__image-block--eb47f2b7.md).  
> You can get by only assigning the name, caption and alt text and let everything else be default.  
> By default, you get a 300px width centered block with a left-aligned caption.
>
> ---
>
> ~

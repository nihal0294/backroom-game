Here's my suggestion  
- Decide what standpoint this is being told from. If it's the M.E.G., use their ranking list for titles(still in the works until the rewrite is done).  
- How I find names is either: use ones that I like and have used before (I'm an avid roleplayer in Discord, haha), or use a Random Name Generator. [This one](https://www.behindthename.com/random/|) is very useful and one that I've used a lot.

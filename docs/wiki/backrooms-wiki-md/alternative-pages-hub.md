# Alternative Pages Hub

The Backrooms are a place of many possibilities and alternate scenarios. Thanks to the CC BY-SA license of the site, any concept found there can be tweaked into something slightly different in terms of direction. In the spirit of the license, we allow such variants to be posted on the site.

This hub displays all alternative pages of already existing articles present in the main lists. In order to have a more intuitive navigation, they are separate from their original writings. You can view them as standalone what-ifs taking different stances or direction to the same base. [Legacy pages](https://backrooms-oversight.wikidot.com/legacy-authors-list) can also be found here in the event where they got rewritten away from the main lists.

Like any other page on this collaborative site, you are encouraged to develop them in your articles if you wish!

## How to post an alternative page

---

When posting an alternative page, use the link authorname-pagename or canon-pagename. For example "praetor3005-level-0" or "desolation-level-0". If it's the second time you're posting one with the same URL, simply add a "2" after it (and so on). As for the name of the page in itself, it must be different than its inspiration page (for example "Floor 0" or "The Yellow Halls" instead of "Level 0 - "Threshold"" for a standalone, or "Desolation Level 1 - "Concrete Lots" for a desolation canon page).

Tag your entry with the usual tags, but add the **alternate** tag as well, so that the listpage modules can display it.

Remember that you do NOT need approval from the original article author to create an alternative version of it for this list, but that those pages don't go in the main lists either.

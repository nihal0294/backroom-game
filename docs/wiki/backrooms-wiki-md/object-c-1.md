# **Description:**

**Canned Dragon Meat** (also known as "Dragon Meat Can") is a fairly common food item found within C Cluster. Much like Almond Water, **Canned Dragon Meat** appear randomly across various locations; However, unlike the varied containers of Almond Water, **Canned Dragon Meat** is always packaged in standardized, well-sealed gray iron cans.

Naturally, whether **Canned Dragon Meat** is actually made from the so-called "dragon meat" remains unknown. The name of this object comes from the words on the shell of each can:

> ## Canned Dragon Meat
>
>   
>
> *— Made in Backrooms*

# **Properties:**

**Canned Dragon Meat** has been proven safe for consumption and provides various essential nutrients for the human body. The "dragon meat" inside the can has a taste similar to chicken, though slightly tougher.

1. This isn't the place to write out your draft. Go to [http://backrooms-sandbox-2.wikidot.com](index.md) and create a page. Then, copy paste all of your code there.  
2. I really don't like the idea of having a frontrooms (aka the real world) exit. I'm usually fine with a frontrooms exit as long as:

- It's an incredibly well-made page with minimal errors (although, not to be rude, I think your page has too many[1](javascript:;)).
- The exit is actually difficult to perform. What's the fun in creating an easy exit back to the Frontrooms?

The thing about Frontrooms exits is that no current page on the wikidot has an exit to reality. If you want to be the first one, you're going to have to apply what I said in order for people to like your page.

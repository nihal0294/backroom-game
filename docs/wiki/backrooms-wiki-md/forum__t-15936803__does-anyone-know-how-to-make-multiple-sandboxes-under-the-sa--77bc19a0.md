Nemu is right, to a point, but you can only have 1 sandbox. Multiple sandboxes go against the site rules. Tabs are an amazing way to solve the problem. The code minus the quotation marks:

"[[tabview]]  
[[tab tabname]]  
Text here  
[[/tab]]  
[[tab tab2]]  
More text  
[[/tab]]  
[[/tabview]]"

You will get:  

- [*tabname*](javascript:;)
- [*tab2*](javascript:;)

Text here

More text

07 Jun 2023 22:24

You are allowed multiple sandboxes *within a reasonable degree.* If possible, using a tabview to keep multiple drafts in one sandbox page is best. If this isn’t feasible (ex: your drafts use different themes) then you can make another sandbox with urls like “username2”, “username3”, etc.

Generally, if you need more than five or so sandbox pages, it's best to make your own personal wikidot wiki so that you don't take up a lot of space in the sandbox.

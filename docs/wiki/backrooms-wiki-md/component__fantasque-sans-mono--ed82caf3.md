This is a page that includes the [Fantasque Sans Mono](https://github.com/belluzj/fantasque-sans) font for programmers. We use it on the Backrooms wiki as our font for the page edit box and the headers on the main theme, [Hallprint](theme__hallprint--b63c1382.md). We used to grab it from fontlibrary but that stopped functioning in Jan 2024, so here it is in all its glory, compiled by the absolutely fantastic GNOME [Webfont Kit Generator](https://apps.gnome.org/WebfontKitGenerator/).

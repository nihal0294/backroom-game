# Image Resize Widget

W A R N I N G  
**PLEASE DO NOT TOUCH THIS PAGE WITHOUT STAFF PERMISSION.**

**This is a template page used internally by the Backrooms Wiki.**

---

rating: +10[+](javascript:; "I like it")[–](javascript:; "I don't like it")[x](javascript:; "Cancel my vote")

It's happened to us all: you finally find the perfect image, you upload it to your page, and that's when you realize it's a far larger file size than what is allowed. The Backrooms Wiki has a rule that files can't be over 800 kB. The problem is, a lot of images (especially photos) have large file sizes or a resolution much higher than what is needed for their dimensions. This tool makes it easy to resize the image and compress the file so they still look good but stay within the rules. The vibes may be big, but the file size will be small.

All image processing occurs locally. No image opened with this tool will leave your device.

If you are using this tool on a mobile device you will need to switch your browser to "desktop mode".

If this tool does not do what you need, consider using the following alternatives:

- [ImageMagick](index.md) (Cross-Platform)
- [Photopea](index.md) (Cross-Platform; No Download)
- [Paint.NET](index.md) (Windows)

Theme Update

14 Oct 2023 17:27

The designer of the current wiki theme asked us to try and make a new version of the site theme that's more fitting for Backrooms Wiki (the original was meant for SCP Wiki when it was initially designed! It was based off of the NieR:Automata UI if you're curious)

**Technical updates**

- lots of little things under the hood
- header height being different on mobile and on desktop doesn't bug the header design out anymore, I think it used to
- colours that used to be the same are different now
- —background-gradient-distance works
- if you use —header-height-on-desktop somewhere it'll automatically switch to the value of —header-height-on-mobile on mobile

**I like the old theme more…**  
You can use it on your own pages with this secret component, which was made to apply to the site's current themes to make sure they work.

**I found a page that looks broken!**  
Apply that nuliminal component at the very top of the page.  
Please PM staff if you found a broken page if you aren't confident fixing them yourself.

**Branches**  
If you grab the site theme by grabbing code from component:theme, you'll get the new theme. if you grabbed the code from theme:nuliminal, you can swap it for theme:hallprint in the future at your leisure. Consult me first for instructions if you're a branch site, but if you're a sandbox you should be good.

**Credits**  
original theme was by stephlynch  
nuliminal was done by scutoid and viv  
new theme aka hallprint was done by scutoid and beach

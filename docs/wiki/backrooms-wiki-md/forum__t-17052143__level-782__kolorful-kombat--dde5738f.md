Re: Level 782: Kolorful Kombat

27 Feb 2025 16:54

First off: I can see you're trying to fit everything here within the default format. This isn't a requirement, and is in fact largely discouraged — you can still use formal tone, of course, but I'd reccommend changing some things around, like removing the parts before the description section. You could also explain the entities themselves before explaining what they do.

For the main part, though, I don't see any issues with the idea of this level, but the execution could do with some more unique flair. For example, instead of naming the factions after colours, you could give them an interesting name and, optionally, a reason behind it. Giving some testimonies on what members of the factions think of each other could also be interesting — it's up to you what they say, but make sure it fits.

Furthermore, I believe it would work better if you gave more explanations about the current events in the level; sure, there's a war, but why? For example. who's fighting for what? While "unknown" is an explanation, people see it as boring and lacking meaning.

I think adding more links between this level and Level 49 would also make sense — maybe each level's factions could be connected somehow?

Anyway, I do see this level having the potential to be accepted onto the site. It just needs to feel more engaging, and then it should do well.

Draft Critique for object 990

28 Nov 2022 18:55

**OBJECT NUMBER**: 990

**DESCRIPTION**: Object 990 is an ornate, oval shaped mirror, with a frame made mostly out of brass. The design of the frame appears to be a long serpentine creature starting at the top and coming down clockwise back to the top and attempting to consume its own tail. Object 990 has no remarkable physical attributes otherwise. While inanimate objects appear in the mirror as normal, anything considered to be part of an entity will not show up in the reflection. This does not include their clothing, held or worn objects, and any form of non-biological implants, like screws, tooth fillings, braces, etc. When an entity makes contact with Object 990, they will find that they can pass through the glass, and will show up in what is believed to be an alternate version of the backrooms. It's theorized the Object 990 leads to an another level Identical to the level it is in. All objects in the level can be manipulated by moving their counterparts in outside of Object 990. This is also true of objects outside Object 990 when manipulating objects inside Object 990. Entities that normally exist in any level will not be in the mirror level. Instead, the mirror level is occupied entirely by Glass Sculptures.

**HISTORY**: Object 990 was discovered on 3/23/2023. The object was in a basement in [REDACTED]. Object originally discovered by [REDACTED].

Hi! Just gave it a quick read through and I like the concept. It does seem like it could be used by the owner (whomever it may be) as a strong exploratory tool. I think with the creation of this object, there may need to be a lot more explanation. For example, are the "glass sculptures" animate? If so, are they brittle? More things like this. Also when you say "When an entity makes contact…" does that mean any entity? If so, could it be possible that entities do indeed exist within levels? Also if the wielder enters this "alternate" Backrooms, does Object 990 cease to exist in the real version? I feel it must be so because what if someone takes it to a different level with a wanderer still inside? What happens to the environment within Object 990? So a lot of questions arise with the discovery of Object 990 and need ironing out. There are few syntax things, such as: "… form of non-biological implants, such as:" would be better there. Instead of using "It's" maybe using "it is". Hyphenate "oval shaped" (to become "oval-shaped"). "appears to be a long **,** serpentine". Finally, discovery in March next year? This is slightly confusing to me… But all in all this shows a lot of promise and could open up some very exciting things in the Backrooms! (oh yeah capitalise "Backrooms")

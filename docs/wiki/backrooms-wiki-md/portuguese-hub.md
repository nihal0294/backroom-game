# Portuguese Hub

This page is a collection of two types of articles. There are **English translations of Portuguese originals** which are not written originally for this site but for the Portuguese site, and **Portuguese translations of English originals** which are mere redirects to the Portuguese site. If you are a Portuguese user, it's worth your time to visit the Portuguese site to read there and participate!

Read the language FAQ on the [Translation Hub](translation-hub.md) if you have any questions about this page.

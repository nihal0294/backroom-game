So, if you look at different theme's codes, you can see a section called the :root. This controls the very root of the theme coding, and it'll be

```
:root {
   --logo-image: url("http://backrooms-wiki.wikidot.com/local--files/component:theme/logo.svg");
   --header-title: "The Backrooms";
   --header-subtitle: "You've been here before.";
```

  
You can add this in with the [[module css]]  
Make sure you only change the words insides the quotations!

Level 360 - Speak No Evil

27 Aug 2020 10:26

**Page Type:** Level

**Genre (Optional):** Mystery

**Page Layout (Optional):** This Concept will use the same format as a typical Level Article, however will be **entirely** composed of images

**Elevator Pitch:** Level is a series of never-ending halls similar in appearance to a storage unit complex. This Level was discovered in 2017 by an unnamed user. The anomalous behaviours of this Level is its ability to notice when information about it is spoken or written. If an entity/document describes Level 360, the said entity/document disappears from all realities as if they never existed.

**Central Narrative:** None

**Hook/Attention-Grabber:** This is the first level with a “behaviour” similar to an entity.

**Additional Notes:** If any plotholes or nitpicks exist in this concept, please notify me.

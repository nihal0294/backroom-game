The component auto-detects the number of offsets the page has and adapts accordingly, you don't need to do anything!

Using this component is straightforward as well! Hover over "Offsets" to view the list of offsets this page offers, hover away and the timeline collapses!

This component should be put in the **parent page** and *not* in the offsets, and **outside** the ListPages module.

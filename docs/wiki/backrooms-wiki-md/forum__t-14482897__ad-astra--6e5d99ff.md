Flashing Text Collapsible Code

29 Feb 2024 15:48

[show code](javascript:;)

[here you go :3](javascript:;)

## add this bit of code at the top of the page:

[[module css]]  
.flashing .collapsible-block-link {  
animation: flashing 1.5s infinite;  
}

@keyframes flashing {  
0% { opacity: 100% }  
50% { opacity: 0% }  
100% { opacity: 100% }  
}  
[[/module]]

## then, for the actual collapsible:

[[div class="flashing" style="text-align: center"]]  
[[collapsible show="text goes here" hide="ditto"]]  
[[/div]]

hope this helps!

# IMAGE REPLACEMENT PROTOCOL

---

**Step 1:** Upload the new image to the page’s files. You’ll want to give the file a short and memorable name for the sake of organization.  
  
[![1](https://backrooms-wiki.wdfiles.com/local--resized-images/staff:image-replacements/1/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/staff:image-replacements/1)  
  
[![2](https://backrooms-wiki.wdfiles.com/local--resized-images/staff:image-replacements/2/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/staff:image-replacements/2)  
  
[![3](https://backrooms-wiki.wdfiles.com/local--resized-images/staff:image-replacements/3/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/staff:image-replacements/3)  
  
**Step 2:** Copy the new file’s link.  
  
[![4](https://backrooms-wiki.wdfiles.com/local--resized-images/staff:image-replacements/4/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/staff:image-replacements/4)  
  
[![5](https://backrooms-wiki.wdfiles.com/local--resized-images/staff:image-replacements/5/medium.jpg)](https://backrooms-wiki.wdfiles.com/local--files/staff:image-replacements/5)  
  
**Step 3:** Edit the page and find where the old image is in the source code. Replace the link to the old image with a link to the new one.

**Step 4:** Add the credits to the new image in the license box. If a page doesn’t have a license box, add one and move any credits of other images to the license box.

**Step 5:** Delete the file of the old image to save storage space.

**Step 6(optional depending on page):** Add/remove the appropriate tags.

# Description and Characteristics

![Missing alt text.](http://backrooms-wiki.wikidot.com/local--files/object-94/backos-logo.png)

The Back OS™ logo. It's identical to that of Windows 95, except that only the yellow color is used. Maybe it's the work of one of us? Or, maybe some kind of entity? Or could it be the OS itself? Who knows…

**Object 94**, commonly referred to as **Back OS™**, is an operating system famous for being the only functional OS on the BackNET[1](javascript:;), as other operating systems such as Windows or Linux cannot work with the [Wi-Fi](object-21.md)[2](javascript:;).

If you're wondering, Back OS™ is obviously a made-up name. In reality, no one knows its real one, as the OS is only represented by its logo. Given that no apparent “official” name could be found for Object 94, [The Leaders](https://backrooms-wiki.wikidot.com/the-leaders)[3](javascript:;) published a survey on the BackNET in 1990, where "Back OS™" was featured among the multiple choices. This generic yet strangely memorable name gained massive popularity and ended up winning the poll with 78% of the vote, and from that day on, everyone refers to Object 94 as “Back OS™”.

Back OS™ is installed by default on all Backrooms-native computers and connected devices, with no possibility of replacing it or modifying its source code. It is however possible to install it on "Frontrooms devices" by various means, but this action is irreversible as it will permanently replace your current operating system.

**Back OS Mobile™**

Back OS™ can also run on mobile and smaller devices such as tablets, with what looks like an adapted version. The features it offers and the way it works remain broadly the same; only the interface is somewhat different to suit a smaller screen.

**How to Install Back OS™**

**Step 1: Get the source files**

If you want to install Back OS™ on your "Frontrooms device", you'll need a USB flash drive or a hard disk drive containing Back OS™[4](javascript:;). These objects can be found in office spaces such as [Level 4](level-4.md) and office buildings in [Level 11](level-11.md), or inside tech stores and tech aisles of supermarkets. You can also find these objects in technological levels like [Level 120](level-120.md), [Level 502](level-502.md), [Level 0.1](level-0-1.md) or [Level 400](level-400.md)[5](javascript:;). Otherwise, these items can be traded with the [B.N.T.G.](b-n-t-g.md) or [The Backrooms Robotics](https://backrooms-wiki.wikidot.com/the-backrooms-robotics), but the prices are far too high for what it is.

**Step 2: Proceed with the installation**

The OS recognizes device types and automatically selects the appropriate version in case of an installation:

- For computers, plug a USB Flash Drive or insert an HDD containing Back OS™. Next, press F12 at boot time and select “Boot by USB” or "Boot by Disk" - Back OS™ will then install itself.

- For smartphones, you'll have to find a variant of Object 94-A with a USB-A or USB-C connector. Plug it and an installation agent will open, asking if you want to install Back OS™ on your phone. Confirm and the OS will install itself.

# Features and Default Applications

Back OS™ appears to be a mix of Windows 95 and Windows XP (the two most popular operating systems of their respective eras) in their features and their rather simplistic interface.

As a result, **Back OS™** offers most of the applications and features that were available on those operating systems.[8](javascript:;)

Just like “Back OS™”, the default applications only have their logo to identify them, meaning that the names of the following applications have been chosen using the same naming process mentioned earlier. BackNET Explorer™ can mainly be used to access and get information from the [General Public Database](index.md), in case you are lost and want to know about a specific level, object, or entity.

Another popular use is to ask various questions, as the search engine results are surprisingly reliable and accurate. However, there are some exceptions; for example, if you ask "how to exit the Backrooms", the search engine will display only one link. Here is the link in question:

**BackCode Studio™** is an all-in-one code editor allowing you to create [SGML](https://fr.wikipedia.org/wiki/Standard_Generalized_Markup_Language), [HTML](https://fr.wikipedia.org/wiki/Hypertext_Markup_Language), [CSS](https://fr.wikipedia.org/wiki/Feuilles_de_style_en_cascade), [Javascript](https://fr.wikipedia.org/wiki/JavaScript), [C](https://fr.wikipedia.org/wiki/C_(langage)), [C++](https://fr.wikipedia.org/wiki/C%2B%2B) and [Python](https://fr.wikipedia.org/wiki/Python_(langage)) code for your website, although initially only SGML and C were available.

Other programming languages ​​were added over time in this order:

- C++ was added HTML was added with the 4.0.001 update
- HTML was added with the 4.0.004 update
- Python was added with the 4.0.005 update
- Javascript was added with the 4.0.006 update
- CSS was added with the 4.0.007 update.

The most common use of **BackCode Studio™** is to export your code on **BackNET Explorer™** for publishing your website on the BackNET. Anyone with a Back OS™ account can create a new website thanks to BackCode Studio™ by choosing a domain name. There is also a whitelist/blacklist option to restrict access to the site if needed and a permission system to manage reading or writing permissions.

BackCode Studio™ also leaves you the option to create virtual machines with a custom IPv4 address that allows you to develop applications able to interact online.[15](javascript:;)The locations of the servers hosting these virtual machines remain a mystery to this day.

# Network and Cybersecurity

**Offline Mode**

Back OS™ can still work without [Wi-Fi](object-21.md) in case you don't have access to it. However, most of the features and services including The BackRoom™, BackNET Explorer™, etc. won't work. You can also disconnect and connect to the Wi-Fi at will, which is actually useful in some situations…

**Main network and subnet**

As mentioned in the **BackCode Studio™** section, the BackNET seems to divided into two distinct networks. The main one that uses unknown protocols (used by every default features and applications) and the subnet (only used by user-made websites on the BackNET) that uses IPv4.

But since the year 2004, it has been revealed that the second network is vulnerable to cyber attacks. However, these attacks are limited to the IPv4 network, and do not extend to the main network.

Ok, I'll help you first with the appearance of the level, since it's too simple.

---

1 - **Add this at the bottom of the page:**

```
-----
[[include :backrooms-wiki:component:rate]]
[[>]]
[[collapsible show="+ Author & Credits" hide="- Author & Credits"]]
Level written by [[*user (WandererDAVE)]]
[[/collapsible]]
[[/>]]

[[=]]
[[div class="footer-wikiwalk-nav"]]
<< [[[Level n]]] | Level n | [[[Level n]]] >>
[[/div]]
[[/=]]

[[include :backrooms-wiki:component:license-box]]
=====
=====
[[include :backrooms-wiki:component:license-box-end]]
```

2 - **Add this to the start of the level so you can keep everything organized:**

```
[[include :backrooms-wiki:component:level-class
|class=3
]]
[[include component:image-block
|name=image file
|caption=brief description
]]
Brief level information

+ Description
```

3 - **And finally, add this format created by me which is more complete:**

```
+ Description
Information

+ Entities
Beings here

+ Bases, Outposts and Communities
That's

+ Entrances and Exits
++++ Entrances
* This
* Format

++++ Exits
Or this
```

---

Also, remove the "Level Name" and change the title (your name) to "Level n."

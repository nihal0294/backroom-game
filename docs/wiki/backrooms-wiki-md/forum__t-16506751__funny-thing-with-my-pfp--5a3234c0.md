This is what i do if you would like to do something

first find a png that you would like to add (make sure it is an actual png because there are too many fake pngs) then download it

go to [https://www.iloveimg.com/](index.md) and go to the image editor (should be the 6th one and have a pencil icon)

Make sure to upload the image you want as the background first (you might need to got to resize and make it smaller in the editor)

To the right there is a button that says open with an image icon, click it and upload the png(s), and move and rotate them how ever you want

Then press the save button, it has a download icon, it should automatically download after a few seconds, but if it doesn't you can manually download it

You now have an edited image

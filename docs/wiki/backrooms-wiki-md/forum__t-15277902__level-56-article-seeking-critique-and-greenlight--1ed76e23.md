Hiya! I stumbled across your level idea, and decided to critique your level!

Firstly, I want to say that I absolutely *love* this idea, and the first image, too! It's overall very well-written, so I want to possibly add a few things I noticed.

- Minor spelling and grammar. Nothing too bad, it's mostly about the punctuation.
- Add an **Author and Image Credits** to the bottom. It's a very important part, especially if there are images that aren't part of the Creative Commons 3.0 license. I'd recommend looking at the [Image Use Policy](image-use-policy.md) for information on that.
- I think a bit more description could be added. Example questions would be: **Is there Wi-Fi or cellular data on this level? If so, is it strong or weak?** as well as **Are there any specific entities exclusive to this level? If so, add a tab view, so you can add the entity on a seperate tab, and edit this post to show where the entity is on your sandbox.**

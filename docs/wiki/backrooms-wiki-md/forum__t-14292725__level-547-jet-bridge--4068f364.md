Level 547 "Jet Bridge"

13 Nov 2021 14:20

**Level 547** is the 548th Level of the Backrooms.

+Description:

Level 547 takes on the appearance of an airport jet bridge. This level seems to be infinite in size with some turns which can be found at any time. Luggage can be found at these turns. For some unknown reason, they cannot be opened with them only being transportable. When exiting the level, the luggage will still be with you, only this time you can open it. When opened you could find almond water, liquid pain, or even Clumps. It has been proven that Entity 2 exists on this level which is common to find.

Luggage isn't the only thing on this level however it is extremely rare to find these items. You could end up finding a computer that could send you to a level. (See "Entrances and Exits") the password for opening the computer is "1247" although you can find the computer already open. Cabinets are very useful on this level but are hard to find. They can be open however they are non-transportable.

Advertisements can be found here which depict going on a holiday to a certain level. These advertisements can show several levels of the backrooms. These adverts show no anomalous or supernatural effect.

+Bases, Outposts, and Communities:  
There are no known bases, outposts, or communities on this level

+Entrances And Exits

Entrances  
You can enter this level by noclipping and finding an airport gate with no lighting on Levels 1, 4, 5, and 36. Entering the jet bridge will cause you to end up at Level 547.

Exits  
You can find a plane which takes you to Level 36. Using the computer and opening a white jpg file will cause to teleport to Level 12.

### Small Critique:

[coding/formatting](javascript:;)

[Hope this helps](javascript:;)

This is just a suggestion, but I recommend during your "Level 547 is the 548th Level of the Backrooms." That you bold the mention of Level 547. Here's how you would do this:

```
**Level 547** is the 548th Level of the Backrooms."
```

  
Oh and one other suggestion: You should probably make your titles bigger. By "titles" I mean things like "Description", "Entrances and Exits", etc. You should probably also have a colon after your title. For  
example:

```
+ Description:
```

  
You can experiment a bit with the size of the title.  
I don't think this is super important in a draft however.

[concept](javascript:;)

[Hope this helps](javascript:;)

The article itself feels a little empty. There isn't quite enough description on this level. All I know is it's a jet bridge and there is luggage. I think you could definitely elaborate more! It's not bad, it just could use some more to it, so that it's easier for the reader to visualize. Perhaps a CC complaint picture to help visualize too? It's not necessary but it could help. For now I recommend you describe the jet bridge more.  
Ex: Color of the jet bridge, texture perhaps? Also maybe you could elaborate a lil more on luggage. Is it heavy, light, does it depend? This isn't necessary but since you're writing to wanderers you need to inform them of the weight, so they'll know if taking the luggage is a struggle/worth the struggle. Oh and is the jet bridge in the air? If so how high.

[SPaG](javascript:;)

[I'm not that good at SPaG crit but I'm trying.](javascript:;)

Okay idk if this counts as SPaG but it sound more formal if instead of "There are no known bases, outposts, or communities on this level" you put "While it is possible to have communities in Level 547, none have been formed yet."

I think you add some unnecessary words/phrases. For example, "Level 547 takes on the appearance of an airport jet bridge. This level seems to be infinite in size with some turns which can be found at any time." This could be stated much more cleanly. "Level 547 appears to be an airport jet bridge. This level is infinite with many turns."

"It has been proven that Entity 2 exists on this level which is common to find." This is kind of out of place considering you were just talking about the luggage. It felt kinda random and spontaneous, also I think it's worded a lil weirdly. Instead, "This level is devoid of entities besides [Entity 2](entity-2.md), which has been proven to live on this level."

Most of this is just some stuff I thought could've been worded better- tbh my SPaG isn't the best, so idk how helpful this is, but I tried. I didn't really analyze the whole level for SPaG but you get the gist of it.

  
Overall pretty nice, but could use some improvement.

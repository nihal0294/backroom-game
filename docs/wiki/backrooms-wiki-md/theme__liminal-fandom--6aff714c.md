# Liminal Fandom Theme

rating: +37[+](javascript:; "I like it")[–](javascript:; "I don't like it")[x](javascript:; "Cancel my vote")

Explore, discover, and document the dark, liminal reality known as the Backrooms, experiencing dread and isolation as you navigate it.

This theme was created by [Stretchsterz](stretchster.md).  
Remix of the "Liminal Theme" by and [etoisle](etoisle.md).  
Based off of the Theme of [The Backrooms Fandom Wiki.](https://backrooms.fandom.com/wiki/Backrooms_Wiki)

To import this theme to your page, put the following text anywhere inside it:

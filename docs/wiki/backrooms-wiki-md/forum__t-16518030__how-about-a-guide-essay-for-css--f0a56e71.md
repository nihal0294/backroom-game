How about a guide/essay for CSS?

12 Dec 2023 18:54

I was just thinking, since you guys are working on a component hub and technical policy, someone could write a guide for that kind of stuff.

I've been wanting to experiment with CSS for a while now, but I find it incredibly intimidating to try to start, and I don't think I'm the only one who thinks that. The most experience I've had with that kind of stuff is changing the color of words. I figure that if someone could write a "How to CSS" guide, it'd make it easier for people to get into it and make themes and custom CSS.

Also, this kind of goes without saying, but I wouldn't be able to write this guide. I'm asking because I barely understand it myself, and would appreciate a public resource for people to dip their toes.

Re: How about a guide/essay for CSS?

12 Dec 2023 20:44

A guide on CSS as a whole would be a bit pointless, because there are already a large number of CSS tutorials online all over the place. However, I think there’s value in having a CSS guide specific to Wikidot and the Backrooms Wiki’s site theme. The site theme was recently changed, so it might take some time to write up a guide on it.

For general CSS resources:

- [W3Schools’ CSS tutorial](https://www.w3schools.com/Css/) is a decent place to start
- [Mozilla’s CSS resources](https://developer.mozilla.org/en-US/docs/Web/CSS) includes some tutorials and the documentation

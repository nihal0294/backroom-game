I don't know how to directly upload it from PC, but I normally:

1. Upload it to my computer
2. Send it to myself via gmail
3. Open it in a new tab
4. Get the image/link source
5. Use the preview/image wizard to see if it works
6. If it doesn't work I fiddle around with it to see if I can get a different link.

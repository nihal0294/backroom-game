"BY allows commercial use  
NC does not  
anything that uses something NC automatically cannot be used for commercial purposes  
if someone else wanted to use something under BY-SA for commercial purposes (which they can), the NC-derived part of the BY-SA work wouldn't be allowed for use  
the BY-SA cannot override the NC nature of the originally-derived media  
or rather, by licensing an NC-derivative work as BY-SA, the BY-SA would "override" the NC, which breaks the terms of the NC license  
and the NC media would no longer be allowed to be used that way" - ghostchibi

Hope that answers the question

Re: Confusion about NC Images

29 Mar 2022 23:25

You're correct that we would not be using the image in a commercial way. However, there is still an issue with how it clashes with CC BY-SA 3.0, which is the license that everything else on the site is under, including the text of the article and the template used when writing the article. CC BY-NC & CC BY-NC-SA both require the work and any adaptation of the work to be non-commercial, but CC BY-SA doesn't allow for us to introduce new restrictions (if you can place any restrictions you want on the use of something, that kind of defeats the purpose of something being copyright-free), and since the requirement for something to be non-commercial is a new restriction, work with the two licenses fundamentally cannot be combined.

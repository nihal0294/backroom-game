A challenge for people good at coding

17 Jan 2024 00:10

Seeing that we are the en branch of the backrooms, we have a problem of half of the people using metric and the other half using imperial. This problem can be footnotes or parentheses converting to the other units, but here is my idea so that people won't have to make 14 footnotes on conversions:

At the top of a page viewers can choose if they want imperial or metric units, this will then make the units in the article show as such. And if possible make it where this is able to be easily replicated so others will be able to do the same.

I have no reward, but i feel like if someone is able to do this, this could add a cool aesthetic to future pages that is assessable to everyone.  
Also if this already exists, or if this is impossible/ extremely hard to make/replicate please tell me so i don't make a big fool of myself

Level XXX - The Time Prison

04 Sep 2021 09:04

**Page Type:** Level

**Genre:** History

**Elevator Pitch:** A jail where the more times you enter a cell and exit, the more different it gets, like it is going further in time.

**Central Narrative:** Level XXX appears to be set in the late 1800s, with yellow stone walls and cameras from that time. The cell blocks are A and B, but both wildly different. Block A is a minimum security block, with minimal paranormal activity, while Block B is the maximum security block, so the prisoners would likely been mentally ill, or very dangerous criminals. Cell Block B is famous for it’s cells, where once you enter one, you exit in another cell. Each time you do this, Level XXX gets more and more different, like it is going further in time. This is likened to the amount of electromagnetic paranormal forces in Block B and quantum physics to do with the retina and sight. The interesting thing is, is that it is different for every person. One man might see the fall of the prison, while another woman might see it become a bustling tourist attraction and ghost tour spot. There is no confirmed pattern for this.

**Hook/Attention-Grabber:** The prison’s future is different for every person.

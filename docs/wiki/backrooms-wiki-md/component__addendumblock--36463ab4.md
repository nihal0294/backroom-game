---

By putting a collapsible inside an addendumblock div, you get an AddendumBlock. An AddendumBlock looks like a button and can be pressed to reveal more content. As you already guessed, this text is inside an AddendumBlock.

[▷ Addendum B1: How can one use AddendumBlocks?](javascript:;)

[▽ Addendum B1: How can one use AddendumBlocks?](javascript:;)

To use AddendumBlocks, paste the following text once anywhere in your article:

[[include :backrooms-wiki:component:addendumblock]]

  
To make an AddendumBlock, place the following text before the collapsible (or group of collapsibles) you want to turn into an AddendumBlock:

```
[[div class="addendumblock"]]
```

  
and the following text after the collapsible (or group of collapsibles):

```
[[/div]]
```

  
Note that all collapsibles inside the addendumblock div will be turned into AddendumBlocks.

[▷ Addendum B2: Neat collapsible code for AddendumBlocks](javascript:;)

[▽ Addendum B2: Neat collapsible code for AddendumBlocks](javascript:;)

The following code was used for the collapsibles in this specific article. However, different code works just as well.

```
[[collapsible show="▷ CollapsibleNameHere" hide="▽ CollapsibleNameHere"]]
**Addendum:** Blocks
**Stuff:** Here
----
Content here!
[[/collapsible]]
```

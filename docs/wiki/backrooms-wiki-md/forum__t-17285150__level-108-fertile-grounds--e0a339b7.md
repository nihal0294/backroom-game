The god's name is a reference to a Lovecraft / Cthulhu Mythos outergod which also possesses connections and imagery to Goats and I presume this is the first or second time it's been used in The Backrooms Wikidot lore. The original version of said outergod's name (from the cthulhu mythos) had a slur soundalike in it (It was written by Lovecraft afterall) so It was probably changed to "Shub-Nozurath" in order to avoid that.

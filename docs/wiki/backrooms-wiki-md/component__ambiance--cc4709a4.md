# Ambiance Component

## Usage

[[include :backrooms-wiki:component:ambiance  
audio=url  
]]

  
for example:

[[include :backrooms-wiki:component:ambiance  
audio=http://thebackrooms.com/cool.mp3  
]]

## Themes

to make the ambiance button look like the rate module on your page's theme, you must use another variable. you need to set theme= to the name from your theme's url.  
for example:

[[include :backrooms-wiki:component:ambiance  
audio=http://thebackrooms.com/jerry\_is\_everything\_yo.mp3  
|theme=bluebird  
]]

## Rate Module

the rate module is meant to be there, and you really shouldn't move it since that's where it's designed to go. but if you really super duper want to you can remove it with norate=1.

> This is a port of the component [Toggle Sidebar BHL](https://scp-wiki.wikidot.com/component:toggle-sidebar-bhl) by from the SCP Wiki.
>
> ## If you want to use it in your page, put:
>
> > [[include :backrooms-wiki:component:toggle-sidebar]]
>
> Use [Toggle Sidebar Theme](component__toggle-sidebar-theme--8d888cc5.md) if you want to use this with a theme hosted on the wiki.  
> ++If you want to use it over [BHL Revert](component__bhl-revert--d17cfa38.md)
>
> > [[include :backrooms-wiki:component:toggle-sidebar-base]]
>
> The base component doesn't have any customization to blend in with NuLiminal theme, so you can just use it over [Show Sidebar](component__show-sidebar--a40acbce.md) if you don't want any customization by default.  
> If you want, you can add this **at the very top** of a theme page, to include it in your theme.
>
> ## To customize it, put:
>
> > [[module css]]  
> > :root {  
> > --toggle-button-bg: hex/rgb/hsl color;  
> > --toggle-border-color: hex/rgb/hsl color;  
> > --toggle-border-width: px/rem/em;  
> > --toggle-icon-color: hex/rgb/hsl color;  
> > --toggle-roundness: percentage;  
> > }  
> > [[/module]]
>

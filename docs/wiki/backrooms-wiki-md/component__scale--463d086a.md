## Scale

This component can be used for any purpose. It can be used as an alternatives for a Survival Difficulty Class, or it could measure anything else!  
This ranges from 1-10, and it can be any color, and it has a built-in title!

### How to Use it

Choose a title, it can be almost anything! This is chosen by {$title}.  
Choose a value, from 1 - 10. This is chosen by {$number}.  
Then, choose a color (must be rgb)! This is chosen by {$color}.

As simple as that!

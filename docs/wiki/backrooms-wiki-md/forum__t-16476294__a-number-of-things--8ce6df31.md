A Number of Things

27 Nov 2023 16:19

This is a large post about different things I've been meaning to bring up, but didn't because I was waiting for the behind-the-scenes drama to simmer down so as not to overwhelm staff.  
  
Here goes.

[Issues](javascript:;)

[– hide block](javascript:;)

- On [How Many Pages?](how-many-pages.md), it says that there are 0 Joke pages.
- For some reason, on the main page, 's profile picture is on the thing for Tales. I know it's a good picture, but there could probably be a more relevant picture there.
- When you go to site search, if you type "joke" into the Filter by Tag box, it gives you 'joke-level', 'joke-entity', and so on, but it doesn't give you 'joke-entry' (You can still filter for 'joke-entry' by manually typing it). However, there are no pages tagged with any of the sub-Joke tags, and they aren't listed on the Tag Guide.

[Ideas](javascript:;)

[– hide block](javascript:;)

- I was wondering if we could maybe get [Random Room](https://backrooms-wiki.wikidot.com/random:random-room) and [Random Tale](random__random-tale--d86e5843.md) added to the respective hub pages.
- How about adding Format Screws to How Many Pages?
- I was also wondering about having a Component Hub for easy access to them. As it is, besides the ones listed on the Guide Hub, the only way to find components is by going to Site Search and filtering by tag 'component'. Speaking as someone who's been here for a comparatively short time, having a hub with easy access to premade components would be a massive benefit to newer writers.
- I was also thinking about possibly adapting the SCP Wiki's [Tales by Series](https://scp-wiki.wikidot.com/scp-series-1-tales-edition|) thing. It can either be a singular page with tabviews, or one page each for Levels, Entities, Objects, Phenomena, and PoIs.

  
Sorry if that was a bit overwhelming, but I didn't want to make these individual posts.

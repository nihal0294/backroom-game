Also, there will be other level numbers such as Level —n (double negative), Level =0 (neutral 0 (there is a positive 0 and a negative 0 so this is what is in between)), Level n÷0, Level A/B/C/D/E/…/AA/AB/AC/… and -A/-B/-C/… (letter levels instead of number levels (for example if a level has AFGABC written in it it might be labeled as Level AFGABC)), Level "n" (possibly would be a combination of every level?), and so on

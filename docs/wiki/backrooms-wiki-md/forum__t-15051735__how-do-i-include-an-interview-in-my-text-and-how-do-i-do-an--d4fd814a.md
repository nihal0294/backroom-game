Well, for any kind of dialogue, such as an interview, a styled quote box may help. Here's the code for that, just replace "Your text goes here" with whatever you need. Make sure to place a second bracket to the left of "div class" and the "/div". I just couldn't do that or else a styled quote box would show instead of the text form. So those two lines should be [[ ]] on the outside, not [ ]]

[div class="styled-quote"]]

Your text goes here

[/div]]

To do an interview type of thing, you can use text like this if you want:

Title of interview and any background information you may need

Character 1: Text here

Character 2: Text here

And so on.

As for the 404 text effect, it seems they have used Javascript to make it happen, with some kind of obfuscator code file they attached to the page. I have no idea how that works, as I know nothing about Javascript. Looking at the page, I'm not even sure what part of the code is doing it. Theoretically, since everything on this site should be CC BY-SA 3.0 compatible, you should be allowed to use it, but you'll want to get someone who knows Javascript to help you with that. And it looks too complicated for me to easily figure out in a day.

[Proposal] New Tag System/Category

23 Oct 2023 14:59

I'd like to propose an additional type of tag in addition to the current types: "Attribute" tags.

On the SCP Wiki, they have a category of tags that are used in relation to the properties of an SCP, such as "humanoid", "hallucination", and "mechanical". I would like to propose a similar system of tags that can be used to do the same in relation to Levels, Entities, Objects, and Phenomena. Below are some ideas for tags that could be created, along with examples and explanations where necessary.

**For Levels**  
-Urban (Level 9, Level 11)  
-Aquatic (Level 7, Level 29, Level 37)  
-Interior (Level 0, Level 1)  
-Industrial (Level 2, Level 3)  
-Wooded (Level 23, Level 32, Level 39, Level 42)  
-Undefined (Level 16, Level 18)[1](javascript:;)  
-Dead End (Level 15, Level 30, The Grave)[2](javascript:;)

**For Entities**  
-Animalistic (Entity 4, Entity 7)  
-Humanoid (Entity 9, Entity 38)  
-Sapient/Intelligent (Entity 25, Entity 83, Entity 134)  
-Botanical (Entity 39, Entity 88)  
-Unique (Entity 18, Entity 101)[3](javascript:;)  
-Digital (Entity 82, Entity 106, Entity 666)  
-Pathogenic (Entity 15, Entity 19)  
-Aquatic (Entity 207)  
-Mechanical (Entity 94, Entity 189)

**For Objects**  
-Unique (Object 6, Object 77)  
-Mechanical (Object 4, Object 8)  
-Manufactured (Object 4, Object 8, Object 20, Object 32)[4](javascript:;)  
-Weaponized (Object 15, Object 20)[5](javascript:;)  
-Consumable (Object 1, Object 5, Object 16)  
-Substance (Object 3, Object 15, Object 17)[6](javascript:;)

**For Phenomena**  
-Pathogenic (Phenomenon 3)  
-Environmental (Phenomenon 9, Phenomenon 15)[7](javascript:;)  
-Personal (Phenomenon 54)[8](javascript:;)

These are all of the tags that I was able to come up with on my own. Any additional ideas are appreciated.

Edit: These are additional ideas that people suggested, as well as any that I thought of after I posted this.

**For Levels**  
-Temporal (Level 87)[9](javascript:;)  
-Bounded (Level 27, Level 28, Level 31, Level 41, Level 42, Level 53, Level 149, Level 333)[10](javascript:;)[11](javascript:;)

Footnotes

[1](javascript:;). Level has no definite/permanent form.

[2](javascript:;). Level has no known exits.

[3](javascript:;). This can include Entities where there is a singular instance [Entity 18] or where there are more than one instance that are clearly unique.[Entity 101]

[4](javascript:;). Object is created by humans or some other species. This doesn't mean that the object was *originally created* by said species, just that they have found a way to create it themselves.

[5](javascript:;). Object is created as and/or often used as a weapon.

[6](javascript:;). Object is a non-consumable substance.

[7](javascript:;). Phenomenon primarily affects the environment.

[8](javascript:;). Phenomenon primarily affects humans and/or Entities

[9](javascript:;). The passage of time within the Level is abnormal, anomalous, or inconsistent. (Thanks, PenOrSaber1!)

[10](javascript:;). The observable and/or explorable area of the Level is finite. This includes Levels that loop (Level 31, Level 53), Levels with natural obstacles that limit the explorable space (Level 27, Level 28, Level 41, Level 42, Level 149), and Levels that are very clearly a limited space (Level 333). Basically, any Level that could be considered to not be infinite would fall under this classification.

[11](javascript:;). Note that the difficulty in traversing Levels 28 and 41 is not what classifies them as "bounded". It is instead the natural obstacles that would prevent one from leaving the bounds of the Level if they were to reach them, those being the mountains and sand dunes, respectively.

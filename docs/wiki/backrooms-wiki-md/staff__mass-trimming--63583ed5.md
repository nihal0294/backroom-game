# Voting Protocol

---

Each Monday, an announcer will bring over the 5 oldest pages that haven't been checked (might change later on if needed). Then greenlighters have until sunday included to discuss which page should get trimmed, opened for rewrite perms, or kept on the site.

> The following people can vote:
>
> - GLs
> - GLTs
> - GFTs
> - Honorary GL team members

### For pages with closed perms

```
Name

https://backrooms-wiki.wikidot.com/anchor

> :thumbsup: - To Keep
> :pencil: - To Rewrite
> :scissors: - To Trim
> :white_circle: - Neutral between “To Rewrite” and “To Trim”
> :french_bread: - Abstain
```

### For pages with open perms (fandom imports or GLMP-owned)

```
Name

https://backrooms-wiki.wikidot.com/anchor

> :thumbsup: - To Keep
> :pencil: - To Rewrite
> :white_circle: - Neutral
> :french_bread: - Abstain
```

The votes can be:

- **To Trim:** If you think the page
  - Isn't important/relevant to the wiki
  - Doesn't have a good enough concept to be improved upon
  - Overall unfixable or unexpandable without being a different article

- **To Rewrite:** If you think the page
  - Has an unexpanded concept or bad execution, but can be improved
  - Is important to the site universe or has been used significantly in some way

- **To Keep:** If you think the page
  - Is good enough for the wiki
  - Has a context that makes it worth keeping (ex: first page by a new author), while being passable

People can only vote for one option but can change votes if they do change their minds.

The staff maintenance team will then move the pages, apply the tags, and make the devlogs as soon as possible during the following week.

### STEP 1: Bucket into Keep or Rewrite/Trim

\* If a new author posted this today, would it survive?  
\* If no, Rewrite/Trim bucket.

- Would I personally upvote the page?
  - If yes, Keep bucket.
- Does it have anything that could realistically be improved?
  - If yes, Rewrite/Trim bucket.
  - If no, Keep bucket.
  - If maybe, Abstain.

### STEP 2: Filter out the Rewrites from the Trims

- Is there lore relevancy?
  - If yes, Rewrite
- Is the concept salvageable?
  - If no, Trim
  - If maybe, Neutral
- Do I think it’s possible to have a competent rewrite of this page?
  - If no, Trim
  - If maybe/yes, Rewrite and/or Neutral depending on how difficult it would be

> note - main 12 levels (just 6 and 7 rn) won't get moved for lore purposes.

# What to do for a trimmed page:

---

- Tag the page with **trimmed** (similar to "archived" but for trimmed pages). (and also **\_trim** like any other pages that got checked for the project).
- Remove the name of the page in its specific page hub (example: level list, object list…)
- Add "(TRIMMED)" at the start of the page title, in order to list it at the end of the tag lists for better sorting
- Open the options menu and click on "rename"

![trim%201.PNG](http://backrooms-wiki.wdfiles.com/local--files/staff%3Amass-trimming/trim%201.PNG)

- Then click "show dependencies" and "select all". This will allow all [[[backlinks]]] to be changed to the new url automatically. Keep all of those backlinks in mind (or screen them) for a future check.

![trim%202.PNG](http://backrooms-wiki.wdfiles.com/local--files/staff%3Amass-trimming/trim%202.PNG)
> Make sure to uncheck the list link and wikiwalk links if appplicable!  
> ![link%20tweak](https://backrooms-wiki.wikidot.com/local--files/staff:mass-trimming/link%20tweak)

- Change the page name by adding **trimmed:** in front of it, leading it to its new category and hiy "rename".

![trim%203.PNG](http://backrooms-wiki.wdfiles.com/local--files/staff%3Amass-trimming/trim%203.PNG)

- The page has moved! If you can, however, check all previous backlinks of the page to verify if they have been changed, and fix how they are displayed if there is an issue (for example [[[trimmed:level-666]]] -> [[[trimmed:level-666|Level 666]]]). An example of a bad link display:

![Capture.PNG](http://backrooms-wiki.wikidot.com/local--files/staff:mass-trimming/Capture.PNG)  
\* REMEMBER THAT THE MAIN LIST AND THE WIKIWALK SHOULD **NOT** redirect to the trimmed page! So in addition of fixing the capitalization and spaces, make sure it remains the normal link too. You can avoid a change by un-checking them in the dependencies before moving the page.
> Remember to devlog it in the special trim devlog each time! A mockup can be found below.

# What to do for a to rewrite page:

---

- All you need to do is tag the page with **to-rewrite** (similar to "archived" but for trimmed pages). (and also **\_trim** like any other pages that got checked for the project).
- On the hub page, add this line next to the page:  ##DD6611|(Trimmed; Open for Rewrite)##
- DM the original author or the page custodian (if possible) asking them if they want to rewrite the page, delete it, or neither. You can find a message mockup below.
- Devlog the page being opened for rewrite alongside the rest of the devlog. A mockup can be found below.
- A week after the DM has been sent, if the author didn't take the perms of if they didn't answer, make a second devlog to announce the page being open for rewrite. A devlog mockup can also be found below.

# What to do for a to keep page:

---

- Simply devlog it will be kept on the site, and tag it with **\_trim**.

# DMing an author to ask if they want to rewrite their page

```
Hello! I am a staff member of the Backrooms wiki, and I am contacting you concerning a page you wrote (or have custody upon), [link].

The page has been voted to be rewritten by our greenlighters. You however have priority on rewriting your page. Would you like to do so? You can also request complete deletion of the article if you wish.

If you do not respond within a week, the assumed answer will be that you are inactive, and the page will be open for other people to apply to rewrite.

Have a nice day!
```

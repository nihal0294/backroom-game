12 Jul 2023 04:26

Have just figured this out.

This is because of a very weird internal glitch of Wikidot, where a single digit zero "0" will never be displayed if enclosed in {{ }}. Here is an example:

Code:

```
Can be displayed normally: {{1}}, {{00}}, {{x0}}, {{0x}};
Doesn't show up: {{0}}.
```

Result:

> Can be displayed normally: 1, 00, x0, 0x;  
> Doesn't show up: .

---

The easiest way to solve this is simply adding an invisible symbol near the 0, e.g., the [zero-width space](https://symbl.cc/en/200B/).

```
CLASS {{[[#ifexpr ({$ent}+{$env}+{$ext})/3 < 0.5 | ★0 ]]
```

Just add a zero-width space at the ★'s position in the original code.

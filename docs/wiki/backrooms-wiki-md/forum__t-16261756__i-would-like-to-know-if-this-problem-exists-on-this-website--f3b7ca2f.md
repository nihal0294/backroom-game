The short answer is that someone has discovered a number-stealing vulnerability in wd, and so far brcn is fine, and someone in scp has been hit.  
At the same time I got a message from the underground black market webmaster (a wikidot Chinese site that is very well known in Chinese circles):  
[ubmh.wikidot.com] Wikipiracy Emergency Notice  
Recently, a huge vulnerability in wikidot has been discovered by a certain organisation, according to the Black Market Station Group, this vulnerability can be identified by putting some hidden codes in the page that will not be detected, so that wikidot user accounts and passwords of users accessing this page will be directly disclosed to the other party, and this kind of malicious attack has already appeared in the SCP Foundation's Central Branch, the Backroom Central Branch, and the Civilian Branch website, as well as Some small wikidot sites have also been implicated.

At present, the underground black market website will enter the first level of alert state, close the user inbound intersection, close the page publishing and editing privileges, close the discussion forums, close all the ways that can be inserted into the malicious code, in order to maximise the protection of the black market users not to be affected by the malicious attacks, and the black market station chief Wells is the first time to investigate this organisation and stop their behaviour, if the situation is bad, Wells does not mind using the power of the spray system to vicious means to stop it forcefully.

The Underground Black Market website team informs other wikidot websites to please defend their websites as soon as possible according to the same state of alert as the Underground Black Market.

I think it seems to be some Chinese organisation that's pulling the strings, but would still like to confirm that the en site doesn't have this kind of interface, after all, I've did‘t see any announcements related to this on this site  
Again: just confirming, no need to get too alarmed.

Re: I would like to know if this problem exists on this website

16 Aug 2023 02:19

Simply put, some people with ulterior motives can post interfaces containing malicious js code on this site. The reply given by the staff of cn site is that the station service personally uses plug-ins that restrict JavaScript functions to ensure the security of the site and members' access. Ordinary members do not have to install or use such plug-ins and do not need to panic about it. (Because the staff of cn site thinks that brcn doesn't have this kind of malicious interface yet, which is not consistent with the situation described by Wells). So far I've only heard of this happening on scp-cn and the underground black market, two large Chinese sites, and other small wd sites, and there's no news of this malicious interface on sites like br-en as of yet, which is why I'm asking about it here.  
There are two reasons why I haven't asked the staff directly, firstly because the response is so inefficient that I don't know if I'll hear from them next month if I send it now, and secondly because maybe some of the brcn staff have already contacted the br-en staff, and the staff just haven't finished reviewing it yet, or they don't think it's going to affect this site. Currently, scp-cn, brcn, and the underground black market have all adopted reasonable defence mechanisms, so there is no high risk of accessing these sites. If you are really afraid that certain pages will affect your account security, then the most viable option is to install a plugin that restricts js functionality, but of course I don't think that's necessary.

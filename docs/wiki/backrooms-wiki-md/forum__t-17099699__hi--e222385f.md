NONONONONO!! NO! DON'T!

Mornin', The CSS Wizard here, and you have just done a ***grave*** mistake. Please, do not ever use this component. It's very poorly coded, old and unmaintained. Instead, the on-site component does have color variables, but it's locked away in the CSS territory. Here, I'll show you:

```
[[include :backrooms-wiki:component:level-class
|class=2
]]

[[module css]]
.sd-container {
  --sd-border-color: 50, 218, 17;
  --sd-bullets: 20, 247, 252;
}
[[/module]]
```

Obviously these are example colors (and arguably look very bad) but it's just an example of how it works. the three numbers are rgb values btw. You can refer to the [component's page](component__level-class--cfeebc7b.md) for all of these color variables.

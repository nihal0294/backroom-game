Level Class Question

02 Jun 2023 18:01

Can I change the class of a level multiple times? I thought so, but I had a reviewer tell me that I needed one consistent class. My level is telling the story of how it changed as if it were happening while the viewer was reading it, and the changing level class is an integral part of it. I would pretty much have to rewrite my rewrite if the answer is no.

Re: Level Class Question

02 Jun 2023 18:27

No, you are completely free to change the level class of a level throughout its page. There are no rules about having inconsistent level properties within a page. The only time you wouldn’t be allowed to do this would be if you were constantly editing the page after it’s been posted to the site.

You’ll probably want to use offsets for this, as a side note.

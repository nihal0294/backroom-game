# Chinese Hub

This page is a collection of two types of articles. There are **English translations of Chinese originals** which are not written originally for this site but for the Chinese site, and **Chinese translations of English originals** which are mere redirects to the Chinese site. If you are a Chinese user, it's worth your time to visit the Chinese site to read there and participate!

Read the language FAQ on the [Translation Hub](translation-hub.md) if you have any questions about this page.

## If you want to translate a page from CN Wiki:

**Fistly, you should be able to read Chinese.**

为了确保翻译质量，我们希望译者满足以下条件：

- 拥有后室英文维基（本站）的成员资格；
- 拥有[后室中文维基](index.md)的成员资格，或在我们的官方 Discord 服务器中；
- 在后室中文维基有至少两篇合格译文（或，在后室英文维基有至少一篇合格原创文章）。

如您满足以上条件，请前往[中译英绿灯审批串](https://backrooms-wiki-cn.wikidot.com/forum/t-17594153/)进行申请。

# What happened?

  
In short, Wikidot went down for a few days. An unknown group from Russia hacked Wikidot's central server, effectively rendering all websites under Wikidot inaccessible.  

# What does this mean?

  
Unfortunately, all users in Russia and Belarus are now unable to access any Wikidot website, as per a ban on all IPs coming from them by Wikidot. This appears to be bypassed via VPN, however, that still heavily limits activity for our [Russian Branch](index.md).

---

Sorry for any issues this causes, we don't have any control over it.

Re: Trying to create a Log Block

11 Oct 2024 16:32

You simply need to use the MEG theme in your article and add this code:

```
[[div class="megbox"]]
+ LOG 001
[[div class="megflavor"]]
**Time:** Time
**Date:** January 13th 2020
**Location:** Level
**Operatives involved:** Team Overseer A/B/C
[[div class="newsbox"]]
+++++ <BEGIN FILE 1>
//[Description of environment]//

**Name:** om thi sis a tex
+++++ <END FILE 1>
-----
+++++ <BEGIN FILE 2> [Optional]
//[Description of environment]//

**Name:** ey i ma its clone ¡
+++++ <END FILE 2>
[[/div]]
-----
[[div class="newsbox"]]
**Result:** Description of the result...
[[/div]]
[[/div]]
[[/div]]
```

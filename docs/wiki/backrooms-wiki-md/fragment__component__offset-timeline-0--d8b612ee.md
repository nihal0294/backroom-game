# Info and How to use

Info and How to use

This component was developed by

Ever had a page with way too many offsets that you want to navigate easily between? now you got the chance!

To Import This Component, Use the following code in your **parent** page:

[[include :backrooms-wiki:component:offset-timeline]]

The component auto-detects the number of offsets the page has and adapts accordingly, you don't need to do anything!

Using this component is straightforward as well! Hover over "Offsets" to view the list of offsets this page offers, hover away and the timeline collapses!

This component should be put in the **parent page** and *not* in the offsets, and **outside** the ListPages module.

  
Use the component to navigate to the next offset, which includes how to remove offset names from the component and other customization options, or click [here](http://backrooms-wiki.wikidot.com/component:offset-timeline/offset/1)

Only the 1K color, roughness, and OpenGL normal maps are included. The
DirectX normal, displacement, preview, USD, and Godot 3 import files are
intentionally omitted.

`wall0_2K_Color.png` was inspected as the old project's primary Level 0
wallpaper reference, but it was not copied. The reference repository does not
record independent provenance for that individual image, so it is unsuitable
for a shipping import until its license is verified separately.
